# LAS-On 매장 조사표 (항목 정의)

매장섭외관리(매장등록)에 필요한 조사 항목 정의서.
현재 구현 코드에서 역추출한 기준 문서다 — 원본 요구사항서(`LAS-On_Store_Manager.md`)가 저장소에 없어 다시 작성했다.

**근거 코드**
- 타입: `web/src/types/store.ts`
- 등록 폼: `web/src/features/store/StoreRegisterModal.tsx`
- 상세/수정: `web/src/features/store/StoreDetailDrawer.tsx`
- 모바일 조회: `web/src/features/store/MobileStoreListPage.tsx`
- 저장소: `server/storeRepo.js` (테이블 `stores`)

표기: 필수 `●` / 조건부필수 `▲` / 선택 `-`
입력위치: `등록` = 매장등록 모달, `상세` = 매장 상세 드로어, `자동` = 시스템 자동 기록

---

## 1. 중복 판정 키 (등록 시 반드시 조사)

신규 등록 시 아래 우선순위로 기존 매장과 중복을 판정한다 (`server/storeRepo.js:131`).

| 순위 | 기준 | 비고 |
|---|---|---|
| 1 | **사업자등록번호** 완전일치 | 하이픈 제거 후 비교 |
| 2 | **매장 전화번호** 일치 | 정규화(숫자만) 후 비교 |
| 3 | **매장명** 부분일치 | 주소 비교는 목록을 보고 사람이 판단 |

→ 현장에서 **사업자등록번호와 매장 전화번호를 우선 확보**해야 중복 등록을 막을 수 있다.

## 10. 섭외이력 (접촉 1회 = 1건)

`RecruitmentLog` — 상세 드로어에서 누적 기록한다.

| 항목 | 필드 | 타입 | 선택지 |
|---|---|---|---|
| 접촉 파트 | `part` | text | |
| 담당자 | `staff` | text | |
| 접촉일 | `contactDate` | date | |
| 접촉방법 | `contactMethod` | select | **방문** / 전화 / 기타 |
| 결과 | `result` | select | **관심** / 보류 / 거절 |
| 다음 액션 | `nextAction` | text | 예: `7/25 재방문` |
| 메모 | `memo` | text | |
| 기록일시 | `createdAt` | datetime | 자동 |

결과 배지 색: 관심=녹색 / 보류=주황 / 거절=빨강
