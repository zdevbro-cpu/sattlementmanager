### 계산 규칙 (작업표와 일치 검증 완료)
```
monthly      = 직급별 연봉 / 12
근로소득      = (소득구분=근로소득) ? 직급별 근로기본급여 : 0
소득공제      = 국민연금* + 건강.요양 + 고용보험 + 소득세   (직급별 정액, 근로소득 발생 시만)
                * 60세 생일 당일부터 국민연금 제외
실지급액(근로) = 근로소득 − 소득공제
사업소득      = (monthly − 근로소득) + 활동비   ← 활동비는 월액, 사업소득에 포함
소득세(사업)   = 사업소득 × 3.3%
실지급액(사업) = 사업소득 − 소득세
지급총액      = 실지급액(근로) + 실지급액(사업)
```
검증: 김은성(1971,부장) 411,550 / 2,788,450, 민복돌(1964) 259,550 / 2,940,450, 김혜남(1960,차장) 259,550 → 작업표와 일치.
